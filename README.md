# 大模型秋招教程（ARIS-in-AI-Offer & Hello-Agents）

## 在线地址

[https://qizishi.github.io/Autumn-Recruitment-Tutorials-for-LLM/](https://qizishi.github.io/Autumn-Recruitment-Tutorials-for-LLM/)

## 简介

这是一个面向大模型秋招准备的中文教程合集网页，汇总了大模型面试中最常见、最核心的知识点，适合在准备秋招、复习基础、梳理系统知识时快速查阅。

## 内容概览

- Attention 与基础推导
- RLHF、DPO、GRPO、PPO 与 reasoning
- MoE、长上下文、KV Cache、量化、分布式训练
- Flow Matching、Diffusion、VAE / VQ-VAE / VQ-GAN
- 图像、视频、3D 生成系统
- 多模态与 Agent
- 大模型秋招面试问答总结

网页中的内容主要由各章节教程页面组成，既包含基础原理，也包含工程实现、训练方法、系统优化和高频面试题总结，方便按主题逐页浏览。

## 说明

- 网页由首页导航和各章节教程页组成，便于按主题浏览。
- 如果你想快速复习，可以先从基础、系统、生成式模型，再到多模态和 Agent。
- 页面中的内容以 HTML 形式发布，适合直接在线阅读。
