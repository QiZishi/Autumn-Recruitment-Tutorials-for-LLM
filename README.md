# 大模型秋招教程（ARIS-in-AI-Offer & Hello-Agents）

> 本书整理自 [ARIS-in-AI-Offer](https://github.com/wanshuiyin/ARIS-in-AI-Offer) 和 [Hello-Agents](https://github.com/datawhalechina/hello-agents) 两个开源仓库中的教程与补充材料。

这是一个面向大模型秋招准备的中文教程合集，覆盖：

- Attention 与基础推导
- RLHF、DPO、GRPO、PPO 与 reasoning
- MoE、长上下文、KV Cache、量化、分布式训练
- Flow Matching、Diffusion、VAE / VQ-VAE / VQ-GAN
- 图像、视频、3D 生成系统
- 多模态与 Agent
- 大模型秋招面试问答总结

如果你想快速浏览全书，直接从左侧目录进入对应章节即可。首页上的静态卡片导航仍保留在 [index.html](index.html)，而这里是适合 GitBook 发布的 Markdown 版本。

## 说明

- 教程正文以 `docs/tutorials/*.md` 为准。
- 生成后的 HTML 仍保留在仓库中，便于直接预览和对照。
- 补充总结页位于 `docs/tutorials/extra_doc/`。

## 快速开始

1. 打开左侧目录中的任意章节。
2. 先看基础章节，再看系统和生成类章节。
3. 最后回到补充总结，做交叉题复盘。
