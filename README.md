# 大模型秋招教程（ARIS-in-AI-Offer & Hello-Agents）

> 本教程整理自 [ARIS-in-AI-Offer](https://github.com/wanshuiyin/ARIS-in-AI-Offer) 和 [Hello-Agents](https://github.com/datawhalechina/hello-agents) 两个开源仓库中的教程与补充材料。

这是一个面向大模型秋招准备的中文教程合集，覆盖：

- Attention 与基础推导
- RLHF、DPO、GRPO、PPO 与 reasoning
- MoE、长上下文、KV Cache、量化、分布式训练
- Flow Matching、Diffusion、VAE / VQ-VAE / VQ-GAN
- 图像、视频、3D 生成系统
- 多模态与 Agent
- 大模型秋招面试问答总结
